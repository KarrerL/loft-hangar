# Loft dans un hangar · maquette 3D

Maquette 3D interactive d'un projet de loft aménagé dans un hangar de **14 × 18 m** (6,5 m sous charpente), à visiter directement dans le navigateur.

**Voir la maquette :** ouvrir `index.html` dans Edge ou Chrome, ou utiliser le lien GitHub Pages du dépôt (Settings → Pages).

## Ce qu'on peut faire

- **Vues prédéfinies** : vue d'ensemble, pièces du rez-de-chaussée, cuisine et salon, étage, suite parentale, bureau, salle de sport, voitures, vue depuis le balcon.
- **Visite à pied** en vue subjective : ZQSD ou flèches pour marcher, souris pour regarder, Maj pour courir, Échap pour libérer la souris. Les murs, vitrages et garde-corps bloquent le passage ; l'escalier mène à l'étage.
- **Remplacer les voitures** par un autre modèle `.glb` (boutons « Porsche » et « GT86 », ou glisser-déposer le fichier sur la page). Le choix est mémorisé dans le navigateur.

## Programme

- **Rez-de-chaussée** (bande de 5 m) : chambre d'ami, salle de bain, WC, cellier, cuisine américaine avec îlot et salon, entrée avec local technique.
- **Étage** : salle de bain parentale, dressing, chambre parentale, grand bureau à deux postes, coursive et balcon intérieur.
- **Hangar** : garage deux voitures, salle de sport (power rack, développé couché, haltères, tirage vertical, pec fly, tapis de course), atelier.
